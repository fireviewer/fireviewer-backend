# Contrat de revue humaine

## Dossier de revue

Le backend expose un dossier privé regroupant :

- source ;
- artefacts ;
- détections ;
- pointages ;
- masques ;
- observations ;
- contradictions ;
- propositions spatiales ;
- incertitudes ;
- reason codes ;
- historique des décisions.

## Décisions séparées

### Faits

- accepter ;
- corriger ;
- rejeter ;
- marquer contradictoire ;
- demander une preuve complémentaire.

### Géométrie

- accepter ;
- corriger ;
- invalider des correspondances ;
- déplacer ou supprimer un point ;
- imposer une abstention.

### Rapport

- accepter ;
- éditer ;
- rejeter ;
- différer.

### Média

- modérer ;
- retirer ;
- proposer à la publication ;
- maintenir privé.

### Publication

- publier une révision ;
- retirer ;
- suspendre ;
- restaurer selon la politique.

## Audit

Chaque action conserve :

- acteur ;
- rôle ;
- raison ;
- avant/après ;
- trace ;
- date ;
- révision ;
- preuve de réauthentification lorsque requise.
