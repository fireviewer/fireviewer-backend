# Gates de publication

## Principe

L’existence d’une sortie IA, d’une revue ou d’un score ne suffit pas à publier.

## Gates

### Incident

- identité résolue ;
- état autorisant une publication ;
- absence de suspension ;
- décision opérateur.

### Fait

- contrat valide ;
- preuves accessibles ;
- validation humaine ;
- contradictions visibles ;
- vocabulaire public adapté.

### Géométrie

- référentiel versionné ;
- rapport géométrique ;
- incertitude ;
- validation humaine ;
- absence de statut bloquant.

### Média

- consentement ;
- modération ;
- droits ;
- politique de diffusion ;
- retrait disponible.

### Viewer

- asset immuable ;
- manifeste valide ;
- ETag ;
- fallback sans WebGL ;
- version publique explicite.

## Interdictions

- publication directe du worker ;
- promotion par seuil seul ;
- publication d’une coordonnée générative ;
- fusion d’une simulation avec une observation ;
- publication d’un média parce qu’il a servi de preuve ;
- rafraîchissement public par une observation non vérifiée.
